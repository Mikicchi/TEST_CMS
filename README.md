# Card Market Scout

Quiero hacer un programa que me permita hacer scraping de cardmarket a traves de proxys "https://free-proxy-list.net/en/".

Quiero poder añadir mis cartas para que las analice y me indique si están bajando, subiendo precio o no.
Analizar por expansiones y detectar cuales son las cartas a seguir
Por juegos
Quiero una grafica con las tendencias y una lista con los 10 mas baratos.
Notificaciones para que realice las compras tiempo de actualización configurable para evitar baneos y en caso de baneo cambiar el proxy server.
